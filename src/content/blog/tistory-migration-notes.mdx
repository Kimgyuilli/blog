티스토리에서 가져온 글은 먼저 Markdown으로 변환한 뒤 `src/content/blog`에 넣습니다.

## slug 관리

slug는 파일명에 의존하지 않고 frontmatter의 `slug` 필드로 명시합니다. 기존 URL과 새 URL의 대응 관계는 `public/_redirects`에 추가합니다.

```txt
/123 /blog/tistory-migration-notes/ 301
```

## 이미지 경로

이미지는 `/images/blog/...` 경로로 통일하면 본문 이동 후에도 경로를 예측하기 쉽습니다.

## 문제

문자열 S가 주어졌을 때, 이 문자열에서 단어만 뒤집으려고 한다.

먼저, 문자열 S는 아래와과 같은 규칙을 지킨다.

1.  알파벳 소문자('a'-'z'), 숫자('0'-'9'), 공백(' '), 특수 문자('<', '>')로만 이루어져 있다.
2.  문자열의 시작과 끝은 공백이 아니다.
3.  '<'와 '>'가 문자열에 있는 경우 번갈아가면서 등장하며, '<'이 먼저 등장한다. 또, 두 문자의 개수는 같다.

태그는 '<'로 시작해서 '>'로 끝나는 길이가 3 이상인 부분 문자열이고, '<'와 '>' 사이에는 알파벳 소문자와 공백만 있다. 단어는 알파벳 소문자와 숫자로 이루어진 부분 문자열이고, 연속하는 두 단어는 공백 하나로 구분한다. 태그는 단어가 아니며, 태그와 단어 사이에는 공백이 없다.

## 입력

첫째 줄에 문자열 S가 주어진다. S의 길이는 100,000 이하이다.

## 출력

첫째 줄에 문자열 S의 단어를 뒤집어서 출력한다.

## 코드

```
from sys import stdin
read = list(stdin.readline().strip())
flag = 0
num = 0
deque = []
for _ in range(len(read)):
        if read[_] == '<':
            flag = 1
            deque.append(read[_])
        elif read[_] == '>':
            flag = 0
            deque.append(read[_])
            num = len(deque)
        elif read[_] == ' ':
            deque.append(read[_])
            num = len(deque)
        elif flag == 0:
            deque.insert(num, read[_])
        elif flag == 1:
            deque.append(read[_])
print("".join(deque))
```

## 풀이 및 후기

그렇게 어려운 문제는 아니었다.

전에 만들었던 스택 문제처럼 리스트로 문자열을 받고 플래그 0과 변수를 하나 만들어 플래그가 0일때는 insert를 사용하여 deque에 문자를 앞에서부터 넣어 거꾸로 된 문자열을 만들어주고 <가 나오면 >가 나올때까지 플래그를 1로 바꾸고 플래그가 1인 동안에는 append를 사용해 순서대로 문자를 삽입하도록 했다. ' '(공백)이 나온 경우에는 num에 숫자를 다시 초기화해줘서 삽입 위치를 ' '(공백) 뒤로 바꾸어 공백 다음 문자부터 다시 거꾸로 삽입되도록 하였다.

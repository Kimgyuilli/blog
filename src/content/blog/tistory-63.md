작성일: 2025/10/25

"더 이상 검색을 통해 우리 웹사이트를 방문하는 사람이 없습니다."

2025년 9월 HubSpot의 연례 행사 INBOUND 2025에서 나온 이 발표는 마케팅 업계에 큰 충격을 안겼습니다. 십수 년간 디지털 마케팅의 핵심이었던 INBOUND 마케팅 전략을 스스로 창시한 회사가 이제 그 방식이 더 이상 유효하지 않다고 선언한 것입니다.

무슨 일이 일어난 걸까요?

## INBOUND 마케팅의 흥망성쇠

### INBOUND 마케팅이란?

INBOUND 마케팅은 CRM 전문 기업 HubSpot이 2000년대 중반에 정립한 개념입니다. 기존의 푸시형 광고(Outbound Marketing)와 달리 **고객이 스스로 찾아오게 만드는** 전략입니다.

핵심 원리는 간단합니다:

1.  **가치 있는 콘텐츠 제작** - 블로그, 백서, 가이드 등
2.  **SEO 최적화** - 검색엔진에서 상위 노출
3.  **자연스러운 유입** - 고객이 검색을 통해 웹사이트 방문
4.  **전환** - 방문자를 리드로, 리드를 고객으로

이 전략은 지난 20년간 B2B 마케팅의 표준이 되었고 HubSpot을 수십조 원 가치의 기업으로 성장시켰습니다.

### 무엇이 변했나?

그런데 2025년, HubSpot은 자신들이 세운 게임의 규칙이 더 이상 작동하지 않는다고 인정했습니다. 이유는 명확합니다. **사용자들의 정보 탐색 방식이 근본적으로 바뀌었기 때문**입니다.

## 검색의 진화: 열린 광장에서 닫힌 생태계로

### 과거: 탐색의 시대

과거 검색 엔진은 정보로 가는 **관문**이었습니다:

```
사용자 질문 → 검색엔진 → 링크 목록 → 웹사이트 방문 → 정보 습득
```

사용자는 여러 웹사이트를 방문하고, 정보를 비교하고, 스스로 판단했습니다. 이 과정에서 SEO가 중요했는데 검색 결과 1페이지에 노출되는 것이 곧 트래픽이었고 트래픽은 곧 비즈니스 기회였습니다.

### 현재: 생성의 시대

이제 AI는 정보의 **종착지**가 되었습니다:

```
사용자 질문 → AI → 종합된 답변 (끝)
```

ChatGPT, Claude, Gemini, Perplexity 등의 AI 도구들은 더 이상 링크를 나열하지 않습니다. 대신 여러 소스를 종합하여 **직접 답변을 생성**합니다. 사용자는 굳이 여러 웹사이트를 방문할 필요가 없습니다.

**결과:** 웹사이트 트래픽 감소, 기존 SEO 전략의 효과 하락

## SEO에서 GEO로: 새로운 최적화의 시대

### GEO(Generative Engine Optimization)란?

GEO는 **생성형 AI의 응답에 자신의 콘텐츠가 인용되도록 최적화하는 전략**입니다.

구분 SEO (검색 엔진 최적화) GEO (생성 엔진 최적화)

|     |     |     |
| --- | --- | --- |
| 목표  | 검색 결과 상위 노출 | AI 응답에 인용 |
| 성과 지표 | 검색 순위, 클릭률 | 인용 빈도, 신뢰도 |
| 핵심 전략 | 키워드, 백링크, 기술적 SEO | 권위성, 정확성, 구조화된 데이터 |
| 트래픽 | 직접 방문 | 간접 노출 (브랜드 인지) |

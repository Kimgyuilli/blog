# Concept and principle

**Reader question:** What is this, how does it work, and when should I use it?

Make the key distinction early. Explain the mechanism with a small, accurate example or mental model. Connect it to a real use case and state the conditions under which that explanation holds. Compare neighboring concepts only when the comparison removes a likely misunderstanding.

Check that a reader can answer: what the concept does, why it behaves that way, when it helps, and where it stops helping. Distinguish general principles from framework- or version-specific behavior. If the source is only study notes, do not imply the author has deployed or measured the concept.

# Experiment and validation

**Reader question:** Did the change produce the intended effect?

Define the hypothesis, baseline, comparison condition, metric, and measurement method. Report the observed result with units and enough context to interpret it. Explain confounding factors and what the data can and cannot establish. End with the decision or next measurement the result supports.

Do not turn an experimental plan into a completed result. Avoid percentage or multiplier claims without the underlying measurements. When the source contains only one run or an uncontrolled comparison, describe that limit plainly.

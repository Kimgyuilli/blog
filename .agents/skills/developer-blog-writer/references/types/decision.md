# Design decision

**Reader question:** Why was this option chosen for these constraints?

Name the decision and the system boundary it affects. Make the constraints and evaluation criteria explicit. Compare only plausible alternatives, showing what each gains and costs in this context. State the chosen option, why it won, what is knowingly left unresolved, and what change in conditions would prompt reconsideration.

Distinguish a decision from proof of its effect. If performance, reliability, or cost benefits have not been measured, frame them as expected benefits rather than results. The article can contain an experiment, but use the experiment type when the measurement itself is the main conclusion.
